## Internal-link pattern for every new calculator

1. Calculator links to its parent category.
2. Parent category links to the calculator.
3. Calculator links to 3–5 closely related tools.
4. Homepage features the strongest current tools.
5. Calculator may link to a supporting guide only when the topic has enough distinct informational demand.
6. Supporting guide links back to the calculator.
7. Sitemap includes every canonical indexable URL.

## Content pattern

Above the fold:
- Plain-language H1
- One-sentence task description
- Minimal required inputs
- Clear result
- Advanced settings collapsed

Below the fold:
- How to use
- Formula
- Variables and units
- Worked example
- Accuracy / assumptions / limitations
- FAQ
- Related calculators

Avoid:
- Keyword stuffing
- Meta-keywords tag
- Artificial word-count targets
- Near-duplicate pages targeting the same intent
- Changing formulas to chase SEO terms

## Current status

Paint, Mulch, Board Foot and Stair are now implemented as dedicated calculator pages with dedicated engines, category links, homepage links and sitemap entries. Stair Calculator is intentionally limited to straight-flight geometry, with optional reference checks separated from the core arithmetic.

Current Stair research notes:
- Public keyword research used for the roadmap continues to show about 33.1K/mo for "stair calculator"; refresh volume before making a major portfolio decision.
- Current SERPs contain free tools covering rise/run, riser count, treads, angle and stringer length, so ToolVault differentiates through a compact beginner-first UI, transparent formulas, metric/imperial conversion, fit checks and a non-universal code/reference warning.
- The 2021 IRC official ICC text sets a 7¾ in maximum riser; local adoption and amendments control. ToolVault does not present its optional reference profile as permit or code approval.
- No separate "how to calculate stairs" guide is created yet because the calculator page already contains the complete instructional/search-intent content and should be measured before adding another page for the same cluster.

## Current AC / BTU research notes

AC / BTU is now implemented as a room/zone sizing calculator. Current 2026 SERPs show active free tools from ENERGY STAR-based and rule-of-thumb competitors, including calculators that use room size, ceiling height, sun exposure, occupancy and kitchen use. ToolVault differentiates with plain-English inputs, visible units, transparent breakdowns, the official ENERGY STAR room-AC capacity bands, and an explicit warning that whole-home HVAC sizing needs a detailed load calculation.

Primary reference used for the calculator:
- ENERGY STAR Room Air Conditioners: https://www.energystar.gov/products/room_air_conditioners
- ENERGY STAR publishes the room-area capacity chart, 10% shade/sun adjustments, +600 BTU/h for each regular occupant above two, and +4,000 BTU/h for kitchen use. 
- ToolVault's higher-ceiling adjustment is explicitly labeled as a planning approximation rather than an ENERGY STAR formula.
