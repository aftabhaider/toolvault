# ToolVault 2026 Calculator Portfolio & Keyword Cluster Roadmap

Updated: 2026-10-06

## Strategy

ToolVault should build one strong, genuinely useful calculator page per search intent cluster instead of creating near-duplicate doorway pages.

Priority model:

| Factor | Weight |
|---|---:|
| Search demand | 30% |
| Competition / SERP strength | 20% |
| Free-tool availability | 15% |
| User pain / practical value | 15% |
| Differentiation opportunity | 10% |
| SEO expansion potential | 5% |
| Development feasibility | 5% |

Search-volume figures below are public U.S. keyword signals and should be refreshed before major portfolio decisions. They are opportunity inputs, not guarantees of ranking or traffic.

Intent coverage:

Do not immediately create separate pages for every variant. Only split the cluster later when Search Console or keyword research shows clearly different intent that deserves materially different functionality or content.

## Internal-link pattern for every new calculator

1. Calculator links to its parent category.
2. Parent category links to the calculator.
3. Calculator links to 3–5 closely related tools.
4. Homepage features the strongest current tools.
5. Calculator may link to a supporting guide only when the topic has enough distinct informational demand.
6. Supporting guide links back to the calculator.
7. Sitemap includes every canonical indexable URL.

## Content pattern

Above the fold:
- Plain-language H1
- One-sentence task description
- Minimal required inputs
- Clear result
- Advanced settings collapsed

Below the fold:
- How to use
- Formula
- Variables and units
- Worked example
- Accuracy / assumptions / limitations
- FAQ
- Related calculators

Avoid:
- Keyword stuffing
- Meta-keywords tag
- Artificial word-count targets
- Near-duplicate pages targeting the same intent
- Changing formulas to chase SEO terms

## Measurement loop

After each cluster:
- Request indexing in Search Console for the new canonical URL.
- Validate sitemap inclusion.
- Monitor queries, impressions, CTR, average position and indexed status.
- Identify unexpected long-tail queries.
- Improve the existing page before creating another page for the same intent.
