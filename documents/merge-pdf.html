How it works

Three simple steps

1. Select PDFs

Choose two or more PDF files from your device. Keep files you want included in the final document.

2. Arrange the order

Use the up and down controls beside each file. The first file becomes the beginning of the merged document.

3. Merge and save

Press Merge PDFs and download. Your browser creates one combined PDF for you to save.

Privacy by design

PDF content is processed locally in your browser. ToolVault does not receive or store the selected documents. The PDF library is loaded from a third-party CDN.

Merge PDF files without uploading them

A PDF merger combines the pages from multiple PDF documents into a single file. It is useful when assembling invoices, reports, application documents, scanned pages, class notes or project records into one document.

What happens to my files?

The tool reads your selected files in the browser and builds the merged PDF on your device. The PDF contents are not sent to ToolVault's server. For sensitive documents, use a trusted device and avoid downloading files onto a shared computer.

Tips for a reliable merge

  • Check the file order before merging; the list order becomes the document order.
  • Make sure each file opens normally in a PDF reader before using it here.
  • Password-protected, damaged or unusually structured PDFs may fail to process. Remove protection only when you are authorized to do so.
  • Merging combines pages; it does not edit existing text, remove passwords or perform OCR on scanned pages.

Frequently asked questions

Is this PDF merger free?
Yes. There is no account or payment required to use this page.

Are my PDFs uploaded?
No. The merge runs in your browser. The page loads its PDF-processing library from a third-party CDN, but the selected document files are not uploaded by this tool.

Can I change the order of pages?
You can change the order of files before merging. To rearrange individual pages within a file, a dedicated page-organizing tool is needed.

Can I merge scanned PDFs?
Usually, if they are valid PDFs. This tool preserves their pages; it does not recognize or convert scanned text.

Why did a PDF fail?
The file may be damaged, encrypted, unsupported, or too large for available browser memory. Try opening it in a PDF reader first or process fewer files at a time.
