Compress PDF

Make a PDF smaller for email or upload limits. Choose how strongly to compress; you see the size before and after, and nothing is downloaded if the file would not get smaller.

Drop a PDF hereor
    Compression
    Basic keeps text selectable but saves little. Strong and Extreme turn each page into a compressed image (144 or 96 DPI), which makes scanned and image-heavy PDFs much smaller but means text can no longer be selected.

    Private: files are processed on your device and never uploaded.

    How to use Compress PDF

    1. Choose or drop a PDF.
    2. Pick a compression level. Start with Strong; use Extreme for the smallest file, or Basic if text must stay selectable.
    3. Select Compress PDF and compare the sizes shown before downloading.

    How the levels work

    Basic rewrites the PDF structure more compactly without touching content. Strong and Extreme re-create each page as a JPEG image at a lower resolution, the same approach used for scanned documents, which is where most PDF size comes from.

    When to keep the original

    If a PDF is mostly text, it is usually already small. Strong compression could make it larger or blur small print; in that case the tool tells you and does not download a worse file.

    Frequently asked questions

    How do I reduce a PDF’s file size?

    Choose the PDF, pick Strong and select Compress PDF. The result shows the original and new sizes and the percentage saved.

    Is my PDF uploaded?

    No. Compression runs in your browser with pdf.js and pdf-lib. The file never leaves your device.

    Will the text still be selectable?

    With Basic, yes. Strong and Extreme turn pages into images, so text can be read but not selected or searched.

    Why did my PDF not get smaller?

    Text-only PDFs are already compact. Try Basic for a small saving, or keep the original.
